# Review checklist

Use before marking a chapter `Completed`.

## Educational quality

- [ ] Understandable for the intended audience (Track A / Track B)
- [ ] Prerequisites explained or linked
- [ ] Examples progressive
- [ ] Important terms defined; glossary updated if needed
- [ ] Common misconceptions addressed
- [ ] Exercises meaningful; solutions not spoiling inline
- [ ] Revision and Mastery present for major chapters

## Technical quality

- [ ] Java claims correct for Java 21 primary path
- [ ] Version details verified against official sources
- [ ] Spec vs implementation distinguished
- [ ] APIs used correctly
- [ ] Examples compiled and run; output recorded
- [ ] Edge cases considered

## Documentation quality

- [ ] Headings consistent with template spirit
- [ ] Links valid
- [ ] References included
- [ ] No unnecessary duplication
- [ ] `PROGRESS.md` accurate

## Practical quality

- [ ] Learner knows when to use / not use the concept
- [ ] Realistic application shown where appropriate
- [ ] Common implementation mistakes identified
