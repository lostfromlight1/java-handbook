# References

Central bibliography. Prefer these official sources over secondary blogs when stating language or platform facts.

## Citation policy

1. Official specification (JLS, JVMS)
2. Official JDK / OpenJDK documentation and API docs
3. Official release notes and JEPs
4. Official framework documentation (Spring, etc.)
5. Reputable engineering references
6. Additional reading

Never copy large copyrighted passages; explain concepts and cite.
