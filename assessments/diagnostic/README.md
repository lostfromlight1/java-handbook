# Java Knowledge Diagnostic System

This diagnostic helps **existing Java developers** find gaps. It is a **learning guide**, not a measure of professional ability or hiring fitness.

Beginners (Track A) should start at [Module 00](../../00-programming-foundations/README.md) instead of scoring themselves here.

## How to use

1. Attempt an area assessment without looking at solutions.
2. Check answers in the matching `*-solutions.md` file (created with each assessment).
3. Use the scoring guide below to choose handbook chapters.
4. Prefer **Revision and Mastery** sections in those chapters.

## Scoring guide (per area)

| Result | Meaning | Suggested next step |
|--------|---------|---------------------|
| **Strong** (~80%+ solid explanations, not lucky guesses) | Working knowledge | Skim Revision and Mastery; move on |
| **Partial** | Mixed gaps | Re-read mapped chapters; redo missed question types |
| **Weak** | Foundations missing | Study mapped modules in roadmap order; re-test later |

Do not average all areas into a single “skill score.” Different domains fail independently (for example, strong Spring with weak JMM).

## Question types (when assessments are written)

Each area assessment should include:

- Conceptual questions  
- Code-reading questions  
- Predict-the-output exercises  
- Debugging exercises  
- Practical coding tasks  
- Advanced questions  

Every question maps to a handbook chapter. Solutions include explanations, not one-line answers.
