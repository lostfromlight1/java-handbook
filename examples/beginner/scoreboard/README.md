# Example: Scoreboard

## Purpose

Parallel arrays for related data; indexing and averages.

## Prerequisites

Module 00 Chapter 04; JDK 21

## Compile and run

```bash
javac Scoreboard.java
java Scoreboard
```

## Expected output (verified JDK 21.0.9)

```text
Scoreboard:
Ada -> 95
Grace -> 88
Alan -> 92
Average: 91.66666666666667
```
