# EncapsulationDemo

Module 05 Ch.02 — private state, validation, accessors, abstraction via `Temperature` and `UserAccount`.

```bash
javac EncapsulationDemo.java
java EncapsulationDemo
```

**Verified on Temurin JDK 21.0.12.1:**

```text
celsius=25.0
fahrenheit=77.0
rejected: below absolute zero
user=ada display='Ada Lovelace'
```

Concepts: encapsulation and invariants, factory method `fromCelsius`, `IllegalArgumentException`, getters/setters with trimming.
