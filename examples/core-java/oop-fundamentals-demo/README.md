# OopFundamentalsDemo

Module 05 Ch.01 — class vs object, fields, instance methods, `new`, reference identity (`==`).

```bash
javac OopFundamentalsDemo.java
java OopFundamentalsDemo
```

**Verified on Temurin JDK 21.0.12.1:**

```text
alice withdraw ok=true
Alice balance=85 cents
Bob balance=50 cents
sameRef == alice: true
bob == alice: false
```

Concepts: `BankAccount` as blueprint, two instances via `new`, instance methods, two references to one object, `==` compares references.
