# OverloadingDemo

Module 04 Ch.02 — overloading, varargs, recursion.

```bash
javac OverloadingDemo.java
java OverloadingDemo
```

**Verified on Temurin JDK 21.0.12.1:**

```text
max(3, 9) = 9
max(3, 9, 2) = 9
max(1.5, 2.25) = 2.25
join() = ''
join("a") = 'a'
join("a", "b", "c") = 'a,b,c'
factorial(5) = 120
factorialIter(5) = 120
sumTo(4) = 10
```

Concepts: overload resolution, `String...` varargs, recursive vs iterative factorial.
