# StringsDemo

Module 11 Ch.02 — string pool, `==` vs `equals`, `toUpperCase`, `substring`.

```bash
javac StringsDemo.java
java StringsDemo
```

**Verified on Temurin JDK 21.0.12.1:**

```text
a==b=true
a==c=false
a.equals(c)=true
a=java
upper=JAVA
sub=hand
```

Concepts: literal pooling, `new String`, content equality, common `String` methods.
